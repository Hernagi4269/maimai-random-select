# 楽曲データ源の調査記録

調査日: 2026-11-01（日本時間）

## 結論

本プロジェクトは、セガ公式の公開楽曲一覧が読み込む JSON を唯一の基礎データ源として採用する。

- 楽曲一覧: <https://maimai.sega.jp/song/>
- JSON: <https://maimai.sega.jp/data/maimai_songs.json>
- 取得場所: ローカルのビルド処理または GitHub Actions
- 認証: 不要
- 保存しないもの: ジャケット画像、Cookie、セッション、パスワード、プレイヤーデータ
- 取得できるもの: 曲名、アーティスト、ジャンル、追加バージョン、STD/DX、BASIC～Re:MASTER、表示Lv
- 取得できないもの: 公式の楽曲ID・譜面ID、内部Lv、譜面作者、個人ごとの解禁状況

2026-11-01 の確認では JSON は HTTP 200、約 466 KiB、`Last-Modified: Fri, 30 Oct 2026 00:59:55 GMT` だった。公式ページはこの一覧を「『maimai でらっくす』で遊べる曲」と説明し、解禁が必要な曲には注記を付けている。

ブラウザーから GitHub Pages の Origin を付けた確認では `Access-Control-Allow-Origin` が返らなかった。そのため、Web UI が公式 JSON を直接読む方式ではなく、GitHub Actions がビルド時に取得して同一オリジンの配信用 JSON に正規化する方式にした。

## すぎめーら氏のツール

### あならいざもどき2

公開説明ページと実際のブックマークレット生成処理を確認した。

- ユーザーが `maimaidx.jp/maimai-mobile/` にログインする。
- ブックマークレットが作者サイトの `maidx_tools.js` を、現在開いている maimai でらっくすNETページへ挿入する。
- パスワードを作者サイトへ入力する方式ではなく、ログイン済みページのDOMをその場で解析・装飾する。
- レコード、プレイ履歴、ベスト枠、制覇状況など、開いているページに応じて処理を切り替える。
- 一部機能はスタンダードコースを必要とする。
- GitHub Actionsのような無人環境ではログイン済みブラウザーDOMがないため、このまま自動データ更新には使えない。
- ページ末尾に無断転載禁止が明記されているため、コードや内部Lvデータはコピーしていない。

この仕組みは、認証情報を外部サーバーへ送らずユーザーのブラウザー内で処理する点では合理的である。ただし本システムの「PCを常時起動せず週/月に自動抽選」には向かない。

### らんだまいざー for DX

公開ページ自体は現在も HTTP 200 だが、トップページではランダム選曲ツールへのリンクがコメントアウトされ「提供休止」となっている。実装は `maidx_in_lv_prism.js` という静的配列を読み、ページ内JavaScriptで候補を選ぶ方式だった。

確認できた制約は次のとおり。

- 静的データのため、新曲・削除曲への継続追従ができない。
- 現在の MAGiCAL より前の PRiSM データ名を参照している。
- ページ自身がジャンルデータ未保有と明記している。
- Re:MASTERの追加時期を考慮しない。
- 同サイトのコードは無断転載禁止。

したがって、公開ページが残っていることと、現在の収録曲で安全に使えることは別と判断した。

## 正確性と制限

「現在収録中」は、公式楽曲JSONに存在することを意味する。公式一覧には、条件解禁後に選べる曲も含まれる。特定プレイヤーが今すぐ選べるかは、そのプレイヤーの解禁状況に依存するため保証できない。

公式JSONから曲が削除されれば、次回の毎日デプロイで候補から消える。逆に、公式JSONの更新遅延・誤記・仕様変更は本システム側では補正しない。取得失敗時は古いデータで黙って成功させず、デプロイを失敗させる。

公式JSONには内部Lvがない。非公式値を自動混入すると出典・地域・更新時期が曖昧になるため、スキーマ上は `internalLevel: null` とし、UIでも内部Lvフィルターを出していない。将来、再利用条件が明確な別アダプターを追加したときに有効化できる。

公式の楽曲ID・譜面IDは公開JSONにない。`sort + 曲名 + アーティスト` から本システム内の安定IDを作り、譜面IDはそこへ `STD/DX + 難易度` を連結する。これは公式IDではない。

## 権利への配慮

- 本リポジトリへ公式の全楽曲データやジャケット画像をコミットしない。
- ビルド時に公式公開JSONから必要最小限の文字メタデータだけを配信用成果物へ生成する。
- 公式画像、第三者データセット、既存ツールのコードは再配布しない。
- 出典と非公式ファンツールである旨をUI・READMEに表示する。
- 隠し曲など公開前情報の解析は行わない。

公式JSONにはオープンデータライセンスの明示がない。公開済み楽曲を抽選するための最小メタデータ利用に限定しているが、権利者から停止要請があった場合は取得・公開を停止する。
